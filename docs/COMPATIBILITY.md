# 兼容性与迁移清单

> **最新需求基线（2026-09-18）**：用户明确允许麦克风、普通摄像头和扬声器使用浏览器授权能力，优先采用浏览器普通媒体入口，Windows 原生媒体保留为高级路径。这项指令覆盖旧版“浏览器只做 UI、全部设备由服务访问”的媒体限制。BLE、USB 串口/HID 仍由本地服务连接；实验解析、主分析计算、状态、文件保存和导出仍在服务内。浏览器媒体不等于硬件测量已验收，也不赋予普通相机曝光标定或深度能力。

本表区分源码实现、已执行验证与最终兼容承诺。2026-09-18；Android 固定提交见 IMPLEMENTATION.md。硬件设备尚未提供，不能给出任何型号的“已支持”认证。

## 浏览器媒体的独立验收边界

浏览器权限只允许读取或播放，不等于实验兼容。必须在 localhost / HTTPS 和支持相应媒体接口的浏览器中操作；本机默认 HTTP 地址可作为 localhost 安全上下文。页面不自动打开设备，用户可随时停止并释放，主界面显示实际持有的来源。浏览器输入暂停时仍可持有设备，但服务不写测量容器；停止、清空和切换实验使桥接失效。源断流或后台节流可能触发服务停机，不能把隐藏页当稳定采集时钟。

相机请求尺寸/帧率不是硬件保证，实际尺寸需随帧校验；相机时间为服务接收时间，不是硬件曝光时间戳。音频传送实际 AudioContext 采样率，不能从声卡标称采样率推定物理输入未经重采样。输入背压、相机丢帧、音频连续性、播放欠载与播放/采集时序均须实测。当前未验真实麦克风、扬声器或摄像头，未把浏览器途径当作 Windows 10、原生硬件或完整性能通过证据。

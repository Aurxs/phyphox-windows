# 用手机浏览器开始测量

手机与 Windows 连接同一局域网，全程无需互联网，也不需要安装手机应用。默认先扫码打开电脑的 HTTPS 页面，再按浏览器提示进入和授权；是否允许受保护的传感器接口，仍取决于实际浏览器与证书状态，不能保证所有手机都能跳过证书信任配置。

1. **选择实验。** 在 Windows 实验库搜索“手机”，点击下面任意一个入门实验，会直接进入「设置 → 手机传感器」，显示已选择的实验；此时无需先进入测量界面。其他具有传感器、音频或相机输入的实验可点击卡片下方「手机接入」，先尝试配置兼容输入；普通打开方式保持不变。
2. **连接手机。** 在当前准备页选择手机所在网络的电脑地址，点击「启用并显示连接二维码」。手机系统相机扫码，在系统浏览器点击「连接 Windows」，然后在电脑确认接入。已有有效连接会直接复用，无需再次扫码。也可以从实验库上方「手机连接设置」先准备手机，再选择实验。侧栏统一使用「设置」入口，手机传感器、电脑音视频、外部设备都在同一页分区展示；实验卡片入口直接定位相应区域，无需进入二级页。滚动或离开设置页不会主动断开已连接的手机。
3. **授权并绑定。** 手机上点击该实验需要的传感器按钮，等电脑显示“可用”，点击「绑定到所选实验」。只有真正收到传感器数据后才会显示可用。
4. **开始测量。** 点击「进入实验测量」，再点“开始”。曲线和实验数据保存在 Windows 的实验会话中，可按现有导出功能保存。

| 入门实验 | 手机需要授权 | 显示内容 |
| --- | --- | --- |
| 手机麦克风 | 麦克风 | 真实单声道 PCM 波形和实际采样率；幅度未经过声压标定。 |
| 手机相机颜色 | 摄像头 | 画面中央区域的色相、饱和度和相对亮度；不提供照度或物理曝光测量。 |
| 手机运动 | 运动传感器 | 包含重力的三轴加速度；使用浏览器实际默认采样速率。 |

首版一部手机同时绑定一个实验输入。要更换传感器，先停止并解除绑定，再从实验库选择对应实验、重新启用所需传感器并绑定。连接仍然有效时不会要求重新扫码。角速度与线性加速度也可作为兼容实验的输入，但仅在手机实际提供数据时可用。

请保持手机采集页在前台。点击手机“停止并释放传感器”或切换到后台会停止设备采集；连接仍可用时，返回后重新启用并绑定即可。网络断开或传输拥塞会停止连接，应重新扫码。不要刷新已配对的手机页面，因为临时配对信息不会保存在浏览器历史或本地存储中。

若页面或权限受阻，展开电脑设置中的「浏览器打不开页面或无法授权？」检查。手动信任本机证书是兼容选项，说明见 [首次连接与证书兼容指南](PHONE-FIRST-CONNECTION.md)，不作为默认必经流程。

这些入门实验不包含模拟传感器数据。软件协议测试和开发机浏览器检查不能替代 Android、iPhone 与 Windows 的真实设备验收。

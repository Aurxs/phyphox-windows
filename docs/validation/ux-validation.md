# 用户界面对齐更新验证

日期：2026-09-18。仅记录本次改动的针对性检查；不作为完整产品或真实设备验收。

## 开发机实际浏览器

macOS ARM64，真实 .NET 本地服务及 Playwright 启动的 Chromium，隔离数据目录 `/private/tmp/phyphox-ux-validation`。没有使用伪造服务或设备数据。

- 分类、来源筛选、中文标题、图标、实验顶部工具栏、分页、保存弹窗能显示；实际检查 1440×1000、1200×737 和 800×900 布局及深浅主题。
- 公式输入 3，Enter 提交得到 9；点击清空出现确认，取消后保持数据。开始/暂停按钮和状态实际切换。
- 从页面保存本机快照；用 CSV 表单将明确给定的数值 5 映射到 x 并计算，结果 25。覆盖已有数据前会列出实验与容器并确认；取消保留表单，再确认才执行导入。
- 恢复已保存的快照前确认覆盖；恢复后输入为 3、结果为 9，显示恢复数据来源。
- 服务主动停止再启动后，页面清除旧会话并重新连接，不继续显示之前的运行状态。测试中预期出现连接失败与旧令牌 401，随后自动取得新令牌恢复；这些不是未处理的页面异常。
- 官方 `corpus/valid/view-tests/rangeslider.phyphox`：上限键盘 End 提交为 10；确认清空后滑块位置与显示值同时回到 0。此为官方视图资产，不是硬件测量。
- 官方加速度实验显示中文标题与分页；缺少传感器时开始禁用，并显示配置原因。没有生成替代传感器数据。
- 设备配置表单的串口参数保持空白，用户需按协议填写；页面检查没有扫描、连接或打开硬件。

截图及浏览器状态记录在 `web/output/playwright/ux-*`。部分早期截图在最后的显示单位替换前取得；最终 Windows 截图与文件哈希另列，不将早期截图当作最终软件的单位显示验证。

## 本轮浏览器媒体变更

用户在界面改进过程中明确允许浏览器摄像头/麦克风并要求浏览器扬声器。实现边界已同步 README、开发计划、兼容清单与独立 PDF 指南，BLE/USB 仍在后台。

- 浏览器麦克风/相机桥接：`Storage.Tests --browser-media` 软件测试通过，覆盖配置、暂停隔离、恢复、连续序号、旧流失效、断流超时和受限 PNG ROI 计算；测试字节是协议/数值 fixture，不能代替真实设备。
- 浏览器扬声器：服务数值/协议聚焦检查通过，输出来自已有 AudioMixer 的立体 PCM；暂停、恢复、序号和停止失效检查见 `browser-speaker-service.md`。未实际发声。
- AudioWorklet：3 项分块/单声道与背压测试通过；音频不静默丢样，图片上传可计数丢帧。
- 实际 Chromium 媒体页面：无自动 getUserMedia、AudioContext 或配置请求；单音频输入槽自动选中；Worklet 同源文件成功返回且 CSP 仍为 script-src self；切页保持组件挂载；1920 宽无横向溢出。显式点击后的拒绝分支使用 mock NotAllowedError，明确不作为真实 OS 权限弹窗测试。证据 `browser-media-result.json` 与 `browser-media-verification.md`。
- Graph wheel 改为 passive:false 原生监听，保持缩放数学，最终 Windows 定向验证另列。之前滚动时出现的 passive 警告已定位，未将它混作服务重启的预期错误。
- 官方多普勒实验空音频初始化异常来自 rangefilter 合法输入顺序，按 Android 重复槽位规则修复。原始记录保持空；官方 rangefilter 唯一黄金向量按原容差通过，见 `rangefilter-ux.txt`。没有用生成音频掩盖初始化问题。

宽屏截图中只占左半屏的问题来自测试浏览器固定 800 像素视口；已将视口恢复为 0/0（随真实窗口），临时解除后虽为 1512 像素，但自动化会话刷新会恢复旧覆盖，因此最终改用 viewport:null 新建正常预览窗口，不继续使用窄屏测试会话。软件主区域也解除 1400 像素上限，实验库随宽度分为 1–4 列，多图表在宽屏并排。用户预览保留自然窗口；后续自动化只操作独立浏览器。

## 最后文案与传感器名称调整

按用户反馈，将通用“输入 #0 sensor”改为按实验实际 sensor.type 生成的具体设备名，并在实验页直接显示；保留既有绑定检查和 canStart 结果。真实官方含重力加速度、不含重力加速度、磁力计 3 个 XML 的名称定向检查通过。接口仅追加 inputs.name/sensorType，未改变容器或通信协议。

实验页、设备、媒体与数据页删除重复防御性描述。设备/媒体名称、状态、操作及覆盖确认保留，原始配置、编号、统计与能力细节进入折叠信息。非模拟值约束仍由后端执行，不依赖页面文案。浏览器相机界面移除本就不受支持的光谱方向选择，桥接参数保持原默认 horizontal；未扩大相机能力。

前端 TypeScript/Vite 构建及服务构建通过。前述 Windows 宽屏/媒体结果属于文案精简前的明确资产哈希；最后仅作本机具体提示/媒体布局定向检查，不宣称再次运行完整 Windows 或真实设备验收。

最后文案定向检查已通过：两类传感器名称直接可见，未满足条件仍禁用开始；媒体高级信息默认折叠，无横向溢出，也未自动申请采集或创建 AudioContext。证据见 [文案验证](copy-verification.md) 和 [结构化结果](copy-qa-result.json)。

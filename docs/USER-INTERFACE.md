# 新版界面使用说明

> **最新需求基线（2026-09-18）**：用户明确允许麦克风、普通摄像头和扬声器使用浏览器授权能力，优先采用浏览器普通媒体入口，Windows 原生媒体保留为高级路径。这项指令覆盖旧版“浏览器只做 UI、全部设备由服务访问”的媒体限制。BLE、USB 串口/HID 仍由本地服务连接；实验解析、主分析计算、状态、文件保存和导出仍在服务内。浏览器媒体不等于硬件测量已验收，也不赋予普通相机曝光标定或深度能力。

本说明对应当前源码中的 Windows 浏览器界面。软件仍为移植开发版；操作入口改进不代表硬件兼容性或 Windows 10 已通过验收。运行条件和功能边界分别见 [README](../README.md)、[兼容清单](COMPATIBILITY.md) 和 [验证记录](VALIDATION.md)。

## 从第一个实验开始

1. 解压完整便携文件夹，运行 `start-phyphox.cmd`，保留终端窗口，在浏览器打开终端显示的本机地址。
2. 在“实验库”点击“试试公式实验”，或搜索“公式计算工作台”。初始输入 2 对应结果 4；把输入改为 3，按 Enter 或移开焦点提交，结果应为 9。这是纯计算，不是设备测量。
3. 实验右上方的主按钮依次用于“开始”“暂停”“继续”。暂停保留结果；需要结束当前记录时，在“实验说明与更多操作”中选择“停止实验”。
4. 使用“保存与导出”或页面底部“保存结果”。保存到本机供以后恢复，或下载状态文件、CSV/ZIP、Excel 工作簿。
5. 结束使用时先停止实验，再在终端按 Ctrl+C 退出服务，随后安全移除 U 盘。关闭网页不会停止本地服务。

右上方的问号提供首次使用帮助；语言和主题按钮可切换中英文、深浅主题。实验自身的文字是否有译文取决于资源，不能把界面语言切换当作全部实验已翻译。

## 四个操作入口

| 入口 | 日常用途 |
|---|---|
| 实验库 | 按分类浏览，使用“全部实验 / 官方实验 / 入门与示例 / 我的实验”筛选，或搜索并导入 `.phyphox`、实验 ZIP。导入后归入“我的实验”。 |
| 当前实验 | 查看数值和图表、切换实验分页、提交参数、开始或暂停测量。查看开始按钮下方的设备提示，按需选择“设置音频与相机”或“连接设备”。 |
| 数据与回放 | 保存和恢复快照，映射导入已有数据，独立重算完整记录。 |
| 设置 | 同一页分区管理手机传感器、电脑音视频和外部设备，不需要进入二级页面。常用连接和授权直接操作，高级参数在原地展开。 |

手机入门实验在实验库选择后直接进入设置，先连接手机并绑定所选实验，再进入测量页。已有连接会复用；普通实验仍可直接打开。详细步骤见 [手机实验快速开始](PHONE-QUICKSTART.md)。

切换实验时，若当前已有数据，会出现保留结果的选择：取消、直接切换或保存后切换。正在测量时先暂停。清空数据也需要确认；可先保存，并按实验提供的分组选择清空范围。清空不等于删除磁盘上的导出文件。

## 保存、导入与回放

**保存与恢复。** “保存到本机”和“保存当前快照”保存实验数据与参数，供“数据与回放”中的快照列表恢复。点击“恢复此快照…”后还需确认：运行中的实验会停止，当前数据被替换；设备连接不会随快照恢复。重要结果可以先另存一个快照。

**导出文件。** 状态下载得到 `.phyphox`；CSV 导出实际是含数据表及元数据的 ZIP，解压后再打开 CSV；XLSX 可用兼容表格软件打开。图表工具栏的 PNG 保存的是图片，不能代替原始数值。图表显示点数限制不限制数据导出的完整缓冲区。

**导入已有数据。** 先打开目标实验并停止测量，再到“数据与回放”选择 CSV、TSV 或 WAV 文件：

- CSV/TSV 在表单中选择文件列和目标容器；**表单列号从 1 开始**。指定首行是否为标题、单位及必要的倍率和偏移。TSV 使用制表符。
- 时间可以不指定，或选择以秒为单位的时间列、填写确实已知的采样率；后两者只能选一个，并需指定独立时间容器。不要猜测未知的采样率。
- WAV 选择文件实际存在的音频通道，也可映射文件时间轴；时间来自 WAV 文件自身采样率。服务会检查通道是否存在，不补造缺失通道。
- 明确选择替换还是追加数据，以及是否在导入后分析一次。覆盖已有容器数据时，会再次显示目标实验和容器并要求确认；取消不会发送导入请求。需要保留结果时，先保存快照。

例如将 `value` 标题下一行的 `5` 保存为 CSV：在公式实验中选择文件列 **1**、目标容器 `x`，保留标题行设置，选择替换并勾选“导入后执行一次分析”。导入后结果应为 25，并显示导入数据来源。高级 JSON 入口继续保留；其中的列索引仍从 **0** 开始，与普通表单显示不同。

**独立回放。** 停止实验后刷新记录，选择标记为完整的日志，点击“独立重算并查看”。结果单独展示数值和图表，不覆盖当前实验，不驱动设备。录制中或不完整日志不能冒充完整回放；目前不是具有速度和时间轴控制的逐帧播放器。

## 设备与媒体操作

“连接设备”先扫描并明确选择实际设备，再按厂家资料填写参数。串口、HID、BLE 使用各自的配置表单；复杂协议保留高级设置。设备名字出现在列表中不代表协议已匹配。输入映射需要正确的容器、数值编码和时间条件；替代原手机输入还要确认单位、坐标及标定。控制输出和手动发送需明确理解协议，不自动猜测命令或校验。

进入“音频与摄像头”不会自动开始录音、录像或播放。普通媒体优先使用浏览器入口：

1. 先加载有对应 `audio` / `camera` 输入的实验，停止测量。点击“刷新设备”；授权前设备名称可能隐藏，系统默认来源需授权后核对。
2. 选择实际麦克风或相机，并关联实验输入。“图像设置”中的宽高和帧率是请求值，不能保证设备提供相同参数。
3. 点击“授权并连接麦克风”或“授权并连接摄像头”，接受浏览器权限。麦克风和相机此时实际使用；服务待机只验证数据，不写入实验容器。在“高级信息”查看采样率和尺寸，并留意全局活动标记。
4. 返回当前实验并“开始”才进入测量。暂停保留授权来源，服务不记录暂停期间的新采样；可以继续。停止、清空或切换实验后需重新启用来源。切换工作台页面本身不会关闭已授权来源。
5. 随时点击“停止实验并断开设备”。关闭页面会释放设备；浏览器后台节流、断流或权限撤销可能让服务停止测量，不能保证后台长期采集。音频发送拥塞会停止并提示，避免把缺样数据显示为连续；相机跳帧明确计数。

真实PCM及相机帧仍由服务计算、保存，网页不连接BLE/USB。浏览器可能重采样或处理音频；普通图像只用于后端明确支持的颜色/亮度通道，不保证曝光、光谱或物理亮度标定，不提供深度。相机使用服务接收时间，不能当作硬件曝光时间戳。

**扬声器。** 打开包含音频输出的实验，先暂停或停止测量，在“扬声器”选择“实验音频输出”，将音量调到适当水平（初始为 10%），点击“启用扬声器”。此操作启用浏览器音频上下文，不自动播放测试音，也不一定出现设备权限弹窗；开始实验后才播放服务生成的声音。当前使用浏览器系统默认输出，没有指定扬声器选择器。暂停保留设置但立即停止已排程声音；“停止声音和实验”会关闭播放并请求停止实验。停止、清空、换实验或隐藏浏览器标签/窗口后需要重新启用；工作台内部切页不等于隐藏浏览器。仅支持已实现的循环音频，非循环逐分析触发仍不支持。断联保护不替代真实播放、延迟或同步验收。

Windows原生媒体保留为高级选项。音频可主动枚举，实验使用服务支持的默认设备；相机“探测”会短暂打开设备。采用报告值或填写已知索引、尺寸与帧率，配置不会启动采集，读取最近帧也不会打开相机。曝光物理参数与验证标志只有经过实际核对才填写；不能把设备控制数值当作秒数。

## 与原版的对齐范围

| 范围 | 当前处理 |
|---|---|
| 主要操作习惯 | 保留橙色强调、实验分类、实验标题及顶部开始/暂停、分页、参数控件、清空与保存入口。 |
| Windows 适配 | 增加左侧工作台导航、桌面宽屏布局、设备配置表单、独立快照和回放入口。不是 Android 屏幕的逐像素复制。 |
| 图表 | 已有多数据集、缩放平移、选点、PNG、柱图及色阶等；仍以兼容清单中的实际支持范围为准。 |
| 尚未完全对齐 | 暂停时间叠加、部分特殊控件与图形细节仍有限制；历史叠加最多保存 32 组浏览器收到的变化，不保证包含每轮分析或隐藏分页的历史。 |
| 硬件与验证 | 无能力时显示原因或阻止运行，不用模拟数据替代。真实 BLE/USB、媒体设备、Windows 10 与目标电脑性能仍需各自验收。 |

文件能打开、数值计算正确、设备可用、交互等价是四项不同结论。本说明只解释当前入口和流程，不替代设备协议、兼容性清单或验收记录。
